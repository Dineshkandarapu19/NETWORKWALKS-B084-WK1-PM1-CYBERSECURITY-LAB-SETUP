# W2-PM5 – Network Scanning with Zenmap

## Objective
Perform network discovery and scanning using Zenmap.

## Tasks
1. Install Zenmap.
2. Identify local IP and subnet using ipconfig.
3. Discover live hosts using a ping scan.
4. Record host details and MAC addresses.
5. Generate network topology.
